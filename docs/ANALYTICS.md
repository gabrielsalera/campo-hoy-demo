# Analítica
La migración incluye sesiones, eventos, feedback y leads. Se registrarán únicamente eventos de negocio del prompt, identificador anónimo, campaña y contexto técnico mínimo. No se capturan mouse, notas completas, credenciales ni secretos. Hechos observados deben mostrarse separados de inferencias comerciales. La captura desde UI y el tablero privado permanecen pendientes.
