# Guion de demo (10 minutos)
| Min | Pantalla / acción | Relato y pregunta |
|---|---|---|
| 0–1 | Acceso → **Ingresar a la demo** | “Los registros dispersos ocultan diferencias.” ¿Cómo concilian hoy el stock? |
| 1–2 | Control, tocar KPI de hacienda | Mostrar que todo resumen abre su detalle. ¿Qué cifra necesita ver primero? |
| 2–3 | Hacienda | Contrastar stock declarado y detalle individual sin inventar faltantes. |
| 3–4 | Datos y nube → consistencia | Abrir inconsistencia y explicar evidencia/origen, sin acusar a quien cargó. |
| 4–5 | Nacimientos | Filtrar parto y abrir caravana/madre; explicar demora de carga. |
| 5–6 | Trazabilidad | Buscar una caravana y recorrer su línea temporal. |
| 6–7 | Tambos / Ino | Mostrar próximos partos, tactos y acciones reproductivas. |
| 7–8 | Sanidad y Agenda | Abrir vencimiento y completar una tarea. ¿Qué retiro no puede pasar inadvertido? |
| 8–9 | Desconectar red, crear tarea/nacimiento | Mostrar “Sin señal” y persistencia local; aclarar que la prueba servidor requiere ambiente conectado. |
| 9–10 | Datos y nube / respaldo | Reconectar y sincronizar; cerrar con: ¿probaría este control con datos propios? |
